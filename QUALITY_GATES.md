# QUALITY GATES

Эти проверки обязательны для проектов, подключённых к NRV AI Factory.

## Базовое правило

Задача не считается выполненной только потому, что код изменён. Developer должен проверить результат и указать, что именно было проверено.

## Обязательные проверки

1. Изменены только файлы, относящиеся к задаче.
2. Проект собирается без ошибок, если в репозитории есть build-команда.
3. Нет новых явных ошибок в консоли/логах.
4. Для UI-проработки проверяются desktop и mobile.
5. Для кнопок, форм и навигации проверяется реальное поведение, а не только код.
6. Не должны ломаться соседние экраны и ранее работающие функции.
7. Секреты, токены, пароли и `.env` не попадают в Git.
8. Если какая-либо проверка недоступна, это явно указывается в REPORT.

## Дополнительные проверки по типу проекта

### NRV-DIGITAL
- визуальная целостность;
- адаптив;
- motion и переходы;
- производительность;
- SEO для публичных страниц.

### LOGIX
- бизнес-логика;
- права доступа;
- API и данные;
- формы и состояния ошибок;
- адаптив интерфейса.

### DOKMARKET
- каталог и карточки;
- авторизация;
- документы и загрузки;
- платежные/денежные сценарии — только если реально подключены;
- безопасность и персональные данные;
- SEO публичных страниц.

## RB

RB исключён из NRV AI Factory. Не создавать для него автоматические задачи, не менять код и не применять эти quality gates без нового явного разрешения владельца.
