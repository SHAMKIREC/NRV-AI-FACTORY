# TASK PROTOCOL

Каждая задача должна содержать:

```text
TASK_ID:
PROJECT:
TITLE:
OBJECTIVE:
FILES_TO_INSPECT:
REQUIREMENTS:
DO_NOT_CHANGE:
ACCEPTANCE_CRITERIA:
TEST_REQUIREMENTS:
STATUS:
```

## Правила Manager

1. Одна задача должна иметь проверяемый результат.
2. Указывать, что нельзя менять.
3. Не выдумывать пути файлов до первичного осмотра репозитория.
4. После DONE выбрать следующую задачу исходя из реального состояния проекта, а не старого списка.
5. BLOCKED использовать, когда требуется решение владельца или недоступный ресурс.
